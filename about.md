# XENIA

A gameplay toolkit for Geometry Dash on **Android** and **Windows**: noclip, speedhack, TPS bypass, a macro bot and a few click helpers.

## What is inside

- **Player**: Safe Mode, Noclip, Speedhack (0.1x - 1000x), TPS Bypass
- **Bot**: record and play back `.nxr` macros, bot speed, CBF Bypass, Particle Fixed
- **Macro**: create, load, rename, save and delete macros from the menu
- **Utils**: Straight Ship, Straight Wave, Auto Clicker (Normal / Super), Wave Slide
- **Stats HUD**: FPS, TPS, frame, inputs, CPS, position and more

## Menus

The default **Table** layout shows draggable windows without popups. **Panel** is the older tabbed layout. You can change the layout and the language (English or Indonesian) in Settings.

On Android, tap the **N** logo to open the menu. On Windows, press **Tab** or click the logo.

## Please note

Cheats only work while **Safe Mode is OFF**. A run that uses any cheat is not saved and never reaches a leaderboard. XENIA is made for level showcases.
